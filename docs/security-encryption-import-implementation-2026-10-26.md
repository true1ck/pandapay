## Operator contract

Keep `ENCRYPTION_V2_WRITES_ENABLED=false` and `STATEMENT_IMPORT_RECEIPTS_ENABLED=false` until their schema/reader/client/recovery proofs pass. An explicit blank versioned-writer flag is invalid; unset preserves legacy writes. `ENCRYPTION_WRITE_KEY_ID` is ignored while the writer is off, supporting safe reader pre-provisioning. Do not replace `ENCRYPTION_KEY` or `PHONE_LOOKUP_HMAC_KEY`. All required v2 read keys must remain available throughout the data and backup lifetime; deploying an old reader after v2 writes is an incompatible rollback.

For accepted versioned writes, the release manifest must set `versionedPhoneWrites:true`, name the same `phoneEncryptionWriteKeyId`, register retained reader IDs/version labels, and carry `versioned_phone_writes_acceptance` tied to the exact source/configuration. Receipt activation requires `statementImportReceipts:true` and `statement_import_receipts_acceptance`. These proofs are not created by setting flags. Hosted Compose passes the writer flag/key ID to both auth and its migration process and the receipt flag only to the product API. Example files retain safe disabled defaults.

Provision any future health reader as a distinct bounded login inheriting only `notification_monitor`; the policy names it `notification_monitor_runtime`. `NOTIFICATION_MONITOR_DATABASE_URL` is an operator-probe setting and is not passed to the public API. The probe refuses elevated roles, other memberships, private schema CREATE, and direct column/table privileges across outbox, revisions, worker status and both counter tables. Include its one connection and rollout/process frequency in the physical-cluster budget. It loads no .env and has no fallback to application/admin URLs. Never place URLs, private keys or credentials in reports/Git.

The health RPC uses 180 seconds to classify a missing/fresh aggregate worker; the API uses a stricter 60-second in-process readiness window. A stopped instance is excluded from fresh aggregate worker availability. Suggested initial operator signals are oldest pending over five minutes, near-cap retained/pending storage, expired leases, dead/failed trends, any blocked worker and missing/unavailable workers. These are proposed thresholds, not accepted service objectives; measure and approve them with the actual deployment and independent receiver. Keep optional delivery off until the owner accepts its bounded retention and provider replay behavior.
