## Running the new controls

Normal deployments keep `NEW_ACCOUNT_REGISTRATIONS_PAUSED=false`. Hosted Compose files pass this variable to auth, and the example environment files document it. The flag accepts only explicit `true`/`false` (or unset). Enabling it changes account admission and requires the reviewed `newAccountsPaused` release feature plus hash-bound `signup_pause_acceptance` proof. Existing manifests without the field remain compatible while the flag is off. Apply an operator-approved configuration uniformly across replicas; changing a local shell variable does not change an already running service.

Statement-import concurrency is a conservative local default, not a 100,000/day throughput claim. Retrying a rejected import uses its existing stable import/row keys. No lower-level database work or provider request is scheduled for that rejected import.
