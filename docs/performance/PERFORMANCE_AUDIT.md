# PandaPay mobile performance audit — 31 October 2026

Scope: source inspection and profile emulator trials on `codex/ios-shortcuts-prototype`. Code-path findings are risk evidence, not proof of a particular dropped frame. Image work is deferred per product direction.

| Priority | Path | Finding and impact | Next verified change |
| --- | --- | --- | --- |
| Critical | `app/lib/data/token_store.dart`, `app/lib/app/router.dart` | PandaMark route waits for secure session and onboarding. A true process-cold swipe-away run took 11.77 s from Dart to Home; both SharedPreferences and secure reads were delayed. Three later cold runs took 1.33–1.82 s. | Android main-thread/Perfetto trace and physical-device comparison before credential-path changes. Preserve auth and biometric gates. |
| High | `app/lib/app/providers.dart` Home refresh; `app/lib/features/sync/sync_engine.dart` | Home and sync can issue independent full transaction GETs; Home's cache-first provider can finish before its background network fetch and invalidate visible projections. | Repository-instance identical-query single-flight is under test; next account-scoped refresh ownership and trace request counts. |
| High | `app/lib/data/local/financial_store.dart` | Transaction reads invoke repair hooks; bulk saves loop rows with synchronous SQLite and JSON on Flutter UI isolate. Async wrappers alone do not move that work. | Profile 3k/10k histories and frame overlap. Move versioned repair from reads, then consider worker-owned DB connection with durable sync ordering. |
| High | `app/lib/app/providers.dart` SMS lifecycle | Startup/resume/reconnect/manual/90 s triggers can run broad reconciliation; coalescing now limits concurrent gate entries but can still request a follow-up broad pass. | Measure reasons, work counts, gate wait, UI frames; split due jobs only after capture/retry invariants are tested. |
| Medium | Activity, Spending, Wallet, Subscriptions, Home, Needs Review | Provider invalidations can replace committed content with loaders, creating visible flicker. | Medium | `app/lib/features/insights/subscriptions_screen.dart` | Synchronous observation entity read/filter in widget build may repeat with provider rebuilds. | Move into a scoped projection after row count and build-span measurement. |
