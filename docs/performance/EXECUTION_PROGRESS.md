Router/Home analyzer and focused tests remained green before the tooling stalled on a later aggregate invocation.

The emulator also reported 79 skipped frames, so this run is not a smoothness pass.
- Home refresh deferral: `HomeScreen` now attaches `homeDataRefreshProvider` only after its local-first shell has painted. The first build no longer schedules the multi-request cache-write/invalidation burst while the initial raster pass is in progress; recommendations and engagement consumers remain deferred with the existing secondary sections.
- Activity list virtualization: Activity now uses `ListView.builder` over lightweight row metadata instead of eagerly constructing every transaction tile and tag projection. Summary, selection, grouping, tap, long-press and bulk-action behavior are preserved while large histories only build visible transaction tiles.
