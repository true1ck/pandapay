# WP-13 security implementation

Status is in review for local integration. The verifier foundation is committed as `b861c52`. The remaining server and attestation implementation is ready for integration checks.

Bundle verification passes the WP-09 canonical vectors, checks installed Ed25519 keys, rejects tampering and unsigned downloads, and supports overlapping keys during rotation. The default trust map remains empty until production provisioning.

Server admission verifies App Check RS256 signatures, issuer, project audience, expiry and app IDs against cached JWKS. Monitor mode admits unverified callers with half limits. Enforce mode rejects them. Shared stats exclude unverified devices. Postgres counters enforce both profile and installation limits atomically. Rejections set Retry-After. Entitlement remains configurable and denies downloads when required without a positive callback.

The phone attestation adapter caches tokens until near expiry, coalesces refreshes and uses the debug provider for debug builds. Android uses Play Integrity and iOS uses App Attest. The runtime must include its headers on requests. Production Firebase registrations and a physical-device attestation smoke test remain required.

Verification saved from implementation includes seven server security tests, seven phone tests, the Postgres SQL security test, and the nested server suite. The orchestrator is rerunning integrated checks. The full OWASP release audit and on-device attestation remain open.
