Unmapped categories and unsupported dates leave the original visible for review. The dry run uses an isolated database copy.

The synthetic fixture covers five retained messages and one SMS row without text. November spending changes from 63,000 to 513,000 paise after correcting the cheque, card bill and IPO readings. The count falls from seven to three. Eight migration tests cover rollback, resume, replay, user choices and non-money readings.

The server supersedes legacy rows using stored fact source keys. Known non-money facts can supersede a row without an event, and the audited rollback restores those rows too. The fully migrated private admin rehearsal passes, including nine SMS v2 SQL tests.
