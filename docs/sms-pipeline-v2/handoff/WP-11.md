# WP-11 console rule review

Core implementation on `codex/sms-v2-wp11-console`, based on WP-10 a560c39 and integrated WP-12 correction/example endpoints. Everything remains local and unpushed.

## Implemented

- SMS Pipeline Rules destination with a virtualized 2,000-row rule table, sender/status/family/text filters, hit/correction-rate sorts, skeleton preview, source/change/fact metadata and 7-day rates.
- Version timeline/diff, cohort history, 7/30-day daily activity, examples and actual golden cases matched by the selected rule.
- Domain-schema and shared-lint JSON editor, examples editable in JSON, draft saving, synthetic/redacted local message tester.
- Real browser golden execution using the same interpreter, instrument registry, linker, ledger, categories, scorer, gates, and baseline comparator as the CLI. Candidate hash parity is verified against the server. Publish remains disabled until a saved candidate passes and a reason is given; changing draft/cohort invalidates the report. Pause/rollback need confirmation and reason.
- Template counts/status/provisional JSON and draft promotion; bundle golden summaries, AI daily cost/token usage, and automatic pause list.
- Grouped correction cases with redacted sample, tester count and trace. Fact data fixes open the editor with the correction guidance; not-a-bug needs a reason. Code fixes first save a reviewed synthetic example using the private WP-12 endpoint, then record the decision, download the golden case, and copy `sms-fix-case <caseId>`.
- Shared pure evaluator extraction with CLI forwarding; deterministic public synthetic golden assets and CI freshness check. No new dependency or frozen wire schema.

Category correction publication is a separate reviewed additive integration, described in `requests/WP-11-shared-browser-evaluation.md`; until that commit, category scaffolds display for review instead of entering fact-rule publication.
