# WP-15 integration touch points

The orchestrator authorizes the planned router, Home, transaction detail and card/account detail slots. The existing Needs Review badge delegates to the v2 inbox count only under the flag. The old screen and parser remain unchanged.

Two narrow local service extensions support real review actions: confirmations can suppress a false defect report, and an explicit user merge can retire a fully absorbed event while preserving its anchor/history. Group changes share a savepoint. The local choices remain account-scoped; wire request schemas are unchanged.

SyncPull clears money for rejected instruments and unknown events because the frozen response has no ledger tombstones. The corresponding server change is documented in WP-14-rejected-instrument-projection.md. LedgerStore.forEvent now uses its existing event index so a complete sync does not decode the entire ledger once per event.

New integration_test and tool files are synthetic-only Android smoke support. Existing dev flavor/package isolation is reused. App test configuration only declares the existing Alchemist golden tag.
