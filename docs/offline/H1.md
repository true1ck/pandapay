# H1 - queues, sync engine, clock, sign-out (review fixes)

| # | Fix | Files |
|---|---|---|
| 1 | 403 `phone_required` / `membership_required` classify as `QueueFailure.network` (no attempt, pass stops, nothing parked). Rows are no longer parked by this cause, so no auto-retry of parked rows was added (rows parked by older builds still need Retry). | `data/local/queue_retry_policy.dart` |
| 2 | A chunk failing with 500/502/503/504 aborts the sync: no halving, no attempts. | 3 | A 404 only means "already done" when it carries the server's JSON `error`; a proxy/HTML 404 is a non-counting retry (also in `classifyQueueFailure`). 409 "already ..." matches only the JSON error text. `_goneIsDone` in providers.dart delegates to `goneIsDone`. | `data/local_first/command_outcomes.dart`, `queue_retry_policy.dart`, `app/providers.dart` |
| 4 | `ServerClock`: median of last 5 samples, samples older than 2 min dropped when a new one arrives, max offset 1 day, `now()` never goes backwards; `SyncQueue` persists the last issued clock per namespace (`account_sync_state.last_clock_ms`). `SyncApi.push` sends `strict:true`; `ignoredFields` -> change kept with a plain reason; `no_syncable_fields` permanent; `transient` retried without counting; clamped clocks accepted. Old servers unaffected. | `data/server_clock.dart`, `data/sync_api.dart`, `sync_engine.dart`, `sync_queue.dart` |
